## 삭제와 오류 상태 근거

- 삭제 쿼리는 사용자 RLS 정책 아래에서 동작하며, 원격 자동 검증에서 실제 행을 생성한 뒤 삭제하고 재조회 결과 0건까지 확인했습니다.
- 상세 화면의 삭제 버튼은 실수 방지를 위해 확인 다이얼로그를 거친 뒤 삭제합니다.
- 오류 UI는 `ErrorState` 재사용 컴포넌트로 구현했고, 재시도 클릭이 전달되는지 UI 테스트로 확인했습니다.
- 운영 DB 장애를 의도적으로 만들지 않기 위해 브라우저에서는 강제 장애를 주입하지 않았으며, 실제 원격 성공 경로와 격리된 오류 UI 테스트를 분리했습니다.
